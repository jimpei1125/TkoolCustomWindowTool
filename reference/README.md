# reference/

SCMDesigner が対象とする `SceneCustomMenu.js`（トリアコンタン氏製、MITライセンス）の実ソースを
開発時の参照用に置いている。**このファイルはビルド成果物には含まれず、SCMDesigner が
実行時に読み込むこともない**（CLAUDE.md「絶対に守るルール」3: SceneCustomMenu.js 本体は
改変しない、を参照専用として遵守するためのコピー）。

- 用途: パラメータのフィールド名・型・デフォルト値、`SceneManager` の公開API（`isCustomScene`
  が引数必須であること等）、`setPlacement` の実装等を、推測ではなく実装から確認するため
- 入手時点のバージョン: 1.52.1（`SPEC.md` / `CLAUDE.md` が対象とする 1.53.4 とは近いが
  完全一致ではない点に注意。差分があれば都度確認する）
- 更新した場合は、このファイルとバージョン番号をあわせて更新すること
